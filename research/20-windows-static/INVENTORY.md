### Network modes

Three user-selectable modes, from `0x3135b4`–`0x3135d0`:

- `proxy-tun` — TAP adapter + routes; full-device tunnel.
- `proxy-socks` — local SOCKS listener (`proxy://`, `socksIpPort`, `FVClientProxySocks`).
- `proxy-global` — sets the Windows system proxy via `sysproxy.exe`.

## TAP driver

Summary only — full detail in `driver/TAP.md`.

  `ServiceBinary=%12%\tap0901.sys`.

## Installer

Summary only — full detail in `installer/NSIS.md`.

- NSIS 3.04 Unicode, `requireAdministrator`, 37 payload files, deflate, non-solid.
- Installs to `$PROGRAMFILES\AJiaSu`; writes `HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\AJiaSu`
  with `DisplayName`, `DisplayVersion=4.9.6.0`, `DisplayIcon`, `InstallLocation`, `UninstallString`,
  `URLInfoAbout=https://www.91ajs.com`, `HelpLink`, `Publisher`, `EstimatedSize=0x600`,
  `NoModify=1`, `NoRepair=1`.
- Creates a Start-menu/desktop shortcut (`.lnk`) to `AJiaSu.exe` and writes `config.ini`.
- **Does not install the TAP driver and does not register a service.** The installer's string table
  contains `tapinstall.exe`, `OemVista.inf`, `tap0901.cat`, `tap0901.sys` as bare filenames — what
  `File` copy instructions need — but **no** `install "`, `remove`, `update`, or standalone `tap0901`
  argument, and no `CreateService`/`AddService`/`pnputil`/`netcfg` token. The uninstaller contains
  `tapinstall`/`tap0901`/`devcon` zero times. The full command construction
  (`install "` + `OemVista.inf` + standalone `tap0901`) exists only in `AJiaSu.exe`, which installs
  the driver on first connect. Opcode-level confirmation of the NSIS entry stream was **not**
  performed — see `installer/NSIS.md` §3.

## Open questions

1. **API base URL and tunnel host** — encrypted inside `product.dat`. Static analysis cannot reach
   them. Next: hook `DesktopEngine::bootProduct` / dump the decrypted buffer at runtime (dynamic wave).
2. **`product.dat` cipher** — 2-byte prefix + 51 blocks; `[UNKNOWN]` algorithm/key. Candidates are
   the statically linked mbedTLS AES routines or the internal `buffer_obscure_packet` path; neither
   is confirmed.
3. **`OPV2` / `/s?s=&n=` parameter semantics** — the query values `s` and `n` are `[UNKNOWN]`
   (probably session id and a nonce/counter). Needs a packet capture of the tunnel handshake.
4. **`kapf`, `cuid`, `cseid`, `peip`, `aur`** — four-letter field tags with no documented meaning.
   `cuid` is described in error text as a "client unique id"; `peip` is plausibly a peer IP. All
   `[INFERENCE]` until a live handshake is captured.
5. **Which TAP generation is actually used at runtime** — the app ships 9.21.2 (`tap`) and 9.24.6
   (`tap6`) and picks a directory at runtime (`\tap\tap` vs `\tap\tap6` literals exist). The selection
   rule is `[UNKNOWN]` from static data.
6. **`\tapwin`** — the uninstaller deletes a `\tapwin` directory that does not exist in the payload;
   probably a legacy name from an older build. Unconfirmed.
7. **Certificate pinning** — `AJiaSu.exe` statically links mbedTLS and carries a CA bundle, but no
   pinning literal was found. Absence of a literal is not proof of absence; needs dynamic check.
8. **arm64 sysproxy mislabel** — a PE32 ARMv7 binary in an `arm64` folder. Whether the vendor
