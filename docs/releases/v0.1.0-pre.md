# v0.1.0-pre — release notes

**Status:** pre-release. **Tag:** `v0.1.0-pre`, created **locally only** after the gates in
[`docs/RELEASE.md`](../RELEASE.md) pass. There is no git remote, no pushed tag, no GitHub
Release and no container image. Do not cite a download URL for this version.

**Date:** 2026-10-28. **Base commit:** `901c75b` on branch `panel-design`; the release fixes
land on top of it, so tag the final commit, not this snapshot.

## What this release is

The first public pre-release of the **AJiaSu → API** control plane: an operator-run service
that turns an authorized vendor account into a scoped, lease-based proxy API.

In scope:

- `ajs-accountd` control plane: accounts, catalog and guarded connect/switch, leases, nodes,
  requests/usage, audit, events, schedules, webhooks, backup/restore, operator RBAC, scoped keys.
- The operator dashboard (15 admin routes) and the public `/docs` bundle.
- The loopback data plane: SOCKS5 on `127.0.0.1:13000-13010` and HTTP `CONNECT` on
  `127.0.0.1:14000-14010`, published only through nginx `stream` with TLS.
- The production deploy kit, the packaging script, and the Go/TypeScript SDKs.
- Docs: architecture, operations, release procedure, security model, privacy, this page.

Out of scope and deliberately off:

- Customer portal, orders, plans, epay/Stripe callbacks: **experimental, disabled**
  (`AJS_TENANT_PORTAL=0`). See [`docs/EPAY-STATUS.md`](../EPAY-STATUS.md).
- Multi-slot (`UseCount > 1`): unproven; one active lease per user and platform.
- Two experimental subsystems from earlier milestones (a credential store and an unused
  node-controller seam): removed from the tree.
- High availability: one host, one daemon, one state directory.
- Windows/macOS service wrappers: binaries are provided, service units are Linux-only.

**Authorization.** No written vendor authorization is on file for the live multi-user CONNECT
edge. The live demo is operator-run, invite-only, educational and research-only, with no SLA, and
may be withdrawn at any time. See [`DISCLAIMER.md`](../../DISCLAIMER.md) and
[`README.md`](../../README.md#use-boundary).

## Live hardening applied 2026-10-28

The live host was changed after the 2026-10-27 cutover. These are observed states, not kit
recommendations; the tree still does not reproduce them byte for byte.

- **Daemon.** `AJS_LISTEN=127.0.0.1:2261`; the ad-hoc unit sets `NoNewPrivileges=yes`,
  `PrivateTmp=yes`, `ProtectSystem=full`, `ProtectHome=yes` and `ReadWritePaths=<state>`. It
  still runs as root, has no `User=`, and still has no `AJS_RBAC_STRICT`.
- **Payments/portal.** The live environment no longer carries `AJS_EPAY_*`; the daemon logs
  `epay_disabled` and `stripe_webhook_disabled`, and the portal routes are unregistered.
- **Public API edge.** 120 requests/min with burst 60 per IP, 20 connections/IP, 400 total;
  `client_max_body_size 2m`; CSP, frame, referrer and permissions headers; `server_tokens off`;
  ECDHE-AEAD TLS 1.2 ciphers.
- **HMC internal origin.** The vhost allows only `10.99.0.1` and `127.0.0.1`; a LAN
  `/v1/whoami` answers `403`, and the VPS path answers `401`.
- **chisel.** The authfile is anchored to `127.0.0.1:14000-14010`; the tunnel was reconnected
  and a direct chisel gate check answers `200`.
- **Probes.** `/metrics` now answers `401` (was `404`), `/v1/metrics` `401`, `/readyz` still
  `404`, `/docs` `200`; the public gate answers `407` unauthenticated and `200` with explicit
  Basic auth.

## Known limitations

Security and correctness gaps that a reader must know before deploying:

1. **Revocation latency, and the live binary predates the fix (AZ-01).** At this commit the
   gate revalidates an established flow every 10 s and closes it when the key or lease is
   revoked or expired (AJS-476). The live binary `ajs-accountd-61625b0` predates that watch, so
   on the live host revocation still only stops new sessions until it is redeployed.
2. **Strict RBAC is not live.** The live daemon runs in compatibility mode (no
   `AJS_RBAC_STRICT`) and accepts the legacy shared bearer. The public vhost's documented
   precondition is therefore unmet on the live host.
3. **The live daemon still runs as root.** It now listens on `127.0.0.1:2261` and carries the
   sandbox directives above, but it has no `User=`, no `StateDirectory=`, and runs from a
   scratch directory. Root compromise of the daemon is host compromise.
4. **The VPS→HMC API hop is plaintext HTTP inside WireGuard**; there is no end-to-end TLS/mTLS.
5. **The live dashboard SSE uses a hardcoded server-side bearer** for two exact stream routes,
   limited by source IP, not by a user login.
6. **The live public edge is not reproducible from the tree** (hand-written `:2055` vhost; the
   VPS map is `13000-13010` → chisel `15000-15010`, with the HMC-side forwards restricted to
   `127.0.0.1:14000-14010`). The kit's map is `14000-14010` direct, and the live HSTS still
   lacks `includeSubDomains`.
7. **`/metrics` requires a `metrics:read` key at the public edge** (`401` unauthenticated);
   `/v1/metrics` is also `401` unauthenticated, and `/readyz` is not published there (`404`).
   Point readiness probes at the daemon or the admin origin.
8. **Artifact version identity is the tag + `MANIFEST.txt`**; the binary reports `0.1.0`
   because there is no `-X` version injection.
9. **Redistribution notices are only partially carried.** At this commit the packaging script
   enforces `LICENSE`, `NOTICE` and `THIRD-PARTY-NOTICES.md` inside `dashboard-dist.tar.gz`
   and `deploy-kit.tar.gz` and lists them in `MANIFEST.txt`; the three bare binaries still
   ship as bare executables, so a distributor must include the notices from the kit.
   `--build-dashboard` manifests also embed the staging path (R8).
10. **The dashboard suite is timing-sensitive under load** (R9); run it serial and unloaded.
11. **Payments/portal are experimental and off**; no route charges a card, and the live
    environment has no `AJS_EPAY_*` values.

## Upgrade

There is no earlier public release. From a milestone checkout:

1. Stop `ajs-accountd`; copy `state.json`, `secrets.json` and `device-secrets.json` aside.
2. Replace the binary; install the current unit and vhosts from the kit.
3. Keep `AJS_MASTER_KEY` unchanged or sealed values are lost.
4. Start the daemon, check `/readyz`, then reload nginx.
5. Run one authenticated scoped-key read (`GET /v1/nodes`) and one `CONNECT`.

The state snapshot is **versioned, not additive**: this build writes version 2 and accepts
version 1 (the plaintext device map) by migrating it in place. A version 2 document read by an
older version 1 binary is rejected, so a downgrade requires restoring the pre-upgrade
`state.json` backup — not just swapping the binary. See
[`docs/OPERATIONS.md`](../OPERATIONS.md#upgrade-and-rollback).
