## What this release is

The second public pre-release of the **AJiaSu → API** control plane: an operator-run service that
turns an authorized vendor account into a scoped, lease-based proxy API. The control-plane
surface, dashboard, SDKs, deploy kit and six-asset packaging are unchanged in scope from
`v0.1.0-pre`; this release adds the source-only `ajs` CLI and stamps release identity into the
binaries and the accountd image.

In scope:

- `ajs-accountd` control plane, operator dashboard and the public `/docs` bundle.
- The loopback data plane published only through nginx `stream` with TLS.
- The production deploy kit, the packaging script, and the Go/TypeScript SDKs.
- The read-only `ajs` operator CLI, **built from source** (not a release asset).
- Docs: CLI, admin API, protocol summary, troubleshooting, release procedure, versioning.

Out of scope and deliberately off: customer portal, orders, epay/Stripe callbacks (experimental,
disabled — see [`docs/EPAY-STATUS.md`](../EPAY-STATUS.md)); multi-slot leases; high availability;
Windows/macOS service wrappers.

**Authorization.** No written vendor authorization is on file for the live multi-user CONNECT
edge. The demo is operator-run, invite-only, educational and research-only, with no SLA, and may
be withdrawn at any time. See [`DISCLAIMER.md`](../../DISCLAIMER.md) and
[`README.md`](../../README.md#use-boundary).

## Changes since `v0.1.0-pre`

### Added — read-only `ajs` CLI

`sdk/go/cmd/ajs` is a read-only operator CLI in the Go SDK module, built from source with no
third-party dependency:

```bash
cd sdk/go && go build -o ajs ./cmd/ajs
./ajs status|nodes|leases|lease <id>|doctor
```

It probes `/healthz` and `/readyz`, lists nodes and leases, shows one lease with the gate
connection it points at, and runs a doctor pass over the same reads. It issues `GET` only, has no
mutation or `connect` command, never prints a credential, and is **not** among the release
assets. Full reference: [`docs/CLI.md`](../CLI.md).

### Added — `/readyz` 404 is `SKIP`, not a failure

`ajs status` and `ajs doctor` treat an HTTP 404 from `/readyz` as "the edge does not expose this
endpoint" — the public edge is health-only — and print `SKIP`. `/healthz` remains required, and
any other non-2xx answer (including 401/403 and 5xx) still fails the run.

### Changed — version and commit stamping

`deploy/package.sh` now stamps both the release version and the packaged commit into the daemon:
`-X main.buildVersion=<version>` and `-X main.buildCommitValue=<commit>`. The daemon also gained
`ajs-accountd -version`, which prints `ajs-accountd <version> (<commit>)` before any state,
secret or network access. `daemon/Dockerfile` takes the same values as the `AJS_VERSION` /
`AJS_COMMIT` build args, and `release.yml` passes the pushed tag and commit SHA, so a released
image names its own tag and commit.

### Fixed — Bearer redaction in SDK errors

`APIError.Error()` in the Go SDK now replaces any `Bearer <token>` reflected into a
daemon-supplied message or reason with `Bearer [REDACTED]`. The typed `Reason` field is unchanged,
so `IsScopeRequired`-style checks keep working. The CLI prints the redacted error.

### Fixed — bare `?` in a base URL is rejected

The Go SDK client and the CLI now reject a base URL with a bare trailing `?` (`url.ForceQuery`)
as well as one with a query or fragment. Previously `https://host:2055?` produced
`https://host:2055?/healthz` on the first path join.

### Docs and site

Public docs completed and reviewed: [`docs/CLI.md`](../CLI.md),
[`docs/ADMIN-API.md`](../ADMIN-API.md), [`docs/PROTOCOL.md`](../PROTOCOL.md),
[`docs/TROUBLESHOOTING.md`](../TROUBLESHOOTING.md), [`docs/RELEASE.md`](../RELEASE.md),
[`docs/VERSIONING.md`](../VERSIONING.md) and the [`docs/` index](../README.md). The README first
screen and the bilingual site were rewritten in the same window.

## Version stamping behavior

| Build | `/healthz` and `-version` | Commit |
|---|---|---|
| `deploy/package.sh --version v0.1.0-pre.2` | `v0.1.0-pre.2` | `git rev-parse HEAD` at package time, or `unknown` |
| `release.yml` accountd image | tag from `github.ref_name` | `github.sha` |
| plain `go build` / `go run` / `go test` | `0.1.0` (`api.DefaultVersion`) | toolchain VCS revision or `unknown` |
| local `docker build` without build args | `0.1.0` | `unknown` |

`package.sh` rejects a version containing whitespace or characters outside `A-Za-z0-9._+/-`, and
reduces a non-hex commit to `unknown`, so neither value can split or alter `-ldflags`. The stamped
values are a build convenience: identify a release by its tag and `MANIFEST.txt`, never by the
string a process prints. The published `v0.1.0-pre` binaries predate this injection and still
report `0.1.0`; that is history, not a claim about this tag.

## Known limitations

1. **The CLI is source-only.** There is no CLI binary asset, no separate CLI tag and no `:latest`
   image for it; build it with `cd sdk/go && go build -o ajs ./cmd/ajs`.
2. **The live daemon is still `ajs-accountd-61625b0`.** This release does not update the live
   host. The live binary predates the 10 s entitlement watch, so revocation there still only
   stops new sessions; the live daemon also runs as root without `AJS_RBAC_STRICT`. See
   [`docs/releases/v0.1.0-pre.md`](v0.1.0-pre.md#known-limitations).
3. **The Docker image build is `[UNVERIFIED]` locally.** There is no Docker daemon on the
   release-prep workstation; images are built by `release.yml` only after the tag is pushed, and
   no pull, `deploy/update.sh` run or compose render has been performed against them.
4. **No written vendor authorization** is on file for the live multi-user CONNECT edge.
5. **Invite-only, no SLA.** Keys are admin-issued; there is no signup, no resale and no support
   commitment, and the demo may be withdrawn at any time.
6. **The tag and assets are pending.** Until `v0.1.0-pre.2` is pushed, the published release
   remains `v0.1.0-pre`; the release URL and image tags above do not resolve yet.
7. **The `v0.1.0-pre` assets are unchanged.** They were built before version stamping and were
   not rebuilt, so they still report `0.1.0` and carry no commit.

## Verification

Before tagging, from the repository root:

```bash
git rev-parse --short HEAD          # the release-prep commit you tag
git tag --list 'v*' | wc -l         # 9 before the new tag, 10 after
git ls-remote --tags origin         # v0.1.0-pre until pushed, then also v0.1.0-pre.2
git status --porcelain              # must be empty

SOURCE_DATE_EPOCH=0 bash deploy/package.sh --version v0.1.0-pre.2 --out /tmp/ajs-pkg
(cd /tmp/ajs-pkg && sha256sum -c SHA256SUMS && ./ajs-accountd-linux-amd64 -version)
# expect: ajs-accountd v0.1.0-pre.2 (<commit>)

cd sdk/go && go test -race -count=1 ./...
go build -o ajs ./cmd/ajs && ./ajs --version
```

After the push:

```bash
git ls-remote --tags origin | grep v0.1.0-pre.2
curl -sS https://api.github.com/repos/dwgx/AIJIASU2API/releases/tags/v0.1.0-pre.2 \
  | python -c "import sys,json;d=json.load(sys.stdin);print(d['prerelease'],len(d['assets']))"
# expect: True 6
```
