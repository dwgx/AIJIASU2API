01SERVICES

从密钥到出口，三段可控。

签发、绑定、连接。其余每一层，都是为了执行、计量或解释这三步。

02CAPABILITIES

六块能力，都是承重墙。

没有装饰性的功能。每一块都参与准入、计量或解释，缺一块链路就断。

C/01KEYS

密钥自带边界。

按路由签发作用域，绑定账号与区域，限速写在密钥上。明文只出现一次，存储里只有哈希。

54 个操作携带 x-required-scope

C/02GATE

没有租约，就没有监听。

准入同时检查密钥与租约。吊销即断流，权限每 10 秒复检一次。

C/03EDGE

出口是一张白名单。

API 只放行 41 条路径、54 个受限操作；Gate 只收 CONNECT。公开 SOCKS5 不存在。

C/04CONTRACT

契约是唯一事实源。

OpenAPI 3.1 定义 120 条路径、148 个操作、200 个 schema。边缘白名单从契约派生，不靠手工维护。

C/05SDK

两端同一套类型。

Go 与 TypeScript 客户端共享错误模型、重试与退避。38 个 Go 测试，24 个 TypeScript 测试。

C/06OBSERVE

指标要凭密钥读。

没有 metrics:read，就没有指标。全局读取会被明确拒绝，而不是靠猜测放行；审计轨迹属于契约的一部分。

/metrics 与 /v1/metrics 均需授权

03LIMITS

不是跑分，是边界。

这些是发布版写死的限额与协议事实，不是延迟或可用性承诺。每一项都能在仓库里找到出处。

04ARCHITECTURE

两个平面，一个私有核心。

公网 TLS 在 VPS 终止。守护进程与 Gate 留在私有侧，分别经 WireGuard 与 chisel 抵达。

05ACCESS

三步，接入控制面。

接入是签发的，不是注册的。运营者持有密钥，客户端持有租约。

  1. 01

    签发密钥

    运营者按作用域签发 ajs_sk_ 密钥。密钥只显示一次，存储中只有哈希。

    ajs_sk_…
  2. 02

    创建租约

    把密钥绑定到账号与区域。响应中的 connection.port 落在 13000–13010。

    connection.port
  3. 03

    建立连接

    以 Proxy-Authorization: Basic 发起 HTTPS CONNECT。公开数据面没有 SOCKS5。

    CONNECT :13000
可复制
scoped-key.sh 
# Operator side: issue a scoped key on the loopback daemon.
curl -sS -X POST \
  http://127.0.0.1:2261/v1/scoped-keys \
  -H "Authorization: Bearer $AJS_ADMIN_TOKEN" \
  -H "X-AJS-CSRF: 1" \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "u-10",
    "label": "demo",
    "scopes": ["catalog:read"],
    "accountIds": ["<accountId>"],
    "rateLimitPerMin": 60
  }'

# The secret is returned exactly once.
export AJS_KEY="ajs_sk_…"

# Client side: read the node catalog with that key.
curl -sS https://ajs.dwgx.top:2055/v1/nodes \
  -H "Authorization: Bearer $AJS_KEY"

没有自助注册。密钥绑定到面板用户，并收窄到它指定的账号或区域。

connect.sh 
# connection.port comes from the lease; live map 13000–13010.
# Basic credentials: panel user id + a key holding proxy:connect.
AUTH=$(printf '%s:%s' "$AJS_USER" "$AJS_KEY" | base64 | tr -d '\n')

curl -sS -x "https://gate.dwgx.top:13000" \
  --proxy-header "Proxy-Authorization: Basic $AUTH" \
  https://example.com/

公开数据面仅支持 HTTPS CONNECT。回环上的 SOCKS5 Gate 无法从公网抵达。
