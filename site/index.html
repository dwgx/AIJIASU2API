  • HTTPS CONNECT only
  • No public SOCKS5
  • Payments disabled

What is implemented

Six pieces, one scoped path.

The control plane is deliberately small: issue a key, bind a lease, connect through the edge. Everything else is contract, observability, and refusal.

01

Scoped keys

Admin-issued ajs_sk_ keys with per-route scopes, account and region grants, and per-key rate limits. Shown once; only a hash is stored.

54 operations carry x-required-scope

02

Lease-bound gate

Create and revoke leases with idempotency keys, quota and concurrency limits, and explicit capacity refusals. Admission checks a live key and lease pair.

Flow revalidated every 10 s at this commit

03

HTTPS CONNECT edge

TLS-terminated CONNECT on the live map 13000–13010, with explicit Basic auth. SOCKS5 stays on loopback and is never published.

No public SOCKS5 ingress

04

OpenAPI 3.1 contract

120 paths, 148 operations, and 200 schemas. 54 scoped operations sit on 41 allowlisted paths. The contract is the source of truth.

docs/openapi.json

05

Operator dashboard

React 19 and Vite 6 console with mock and live build modes, 15 admin routes, and the public docs bundle served at /docs.

54 test files · 475/475 passing

06

Go and TypeScript SDKs

In-tree clients with typed errors and retry/backoff, so an integration does not have to reimplement the contract or guess at failure modes.

38 Go test functions · 24 TypeScript tests

Topology

Two planes. One private core.

Public TLS terminates at the VPS. The daemon and gate stay on the private side, reached over WireGuard and chisel.

WireGuard carries the API hop; chisel carries the gate hop. SOCKS5 listeners bind loopback only.

Quickstart

Three commands to the edge.

Keys are issued by the operator, not self-service. The demo is invite-only, best effort, and may be withdrawn.

copy-ready
scoped-key.sh 
# Operator side: issue a scoped key (loopback daemon, admin token).
curl -sS -X POST \
  http://127.0.0.1:2261/v1/scoped-keys \
  -H "Authorization: Bearer $AJS_ADMIN_TOKEN" \
  -H "X-AJS-CSRF: 1" \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "u-10",
    "label": "demo",
    "scopes": ["catalog:read"],
    "accountIds": ["<accountId>"],
    "rateLimitPerMin": 60
  }'

# The response contains "secret": "ajs_sk_…" exactly once.
# Client side: GET the node catalog with that scoped key.
export AJS_KEY="ajs_sk_…"
curl -sS https://ajs.dwgx.top:2055/v1/nodes \
  -H "Authorization: Bearer $AJS_KEY"

No self-service signup. The key is bound to a panel user and narrowed to the accounts or regions it names.

connect.sh 
# Lease port comes from connection.port; live map 13000–13010.
# Basic credentials: panel user id + a key with proxy:connect.
AUTH=$(printf '%s:%s' "$AJS_USER" "$AJS_KEY" | base64 | tr -d '\n')

curl -sS -x "https://gate.dwgx.top:13000" \
  --proxy-header "Proxy-Authorization: Basic $AUTH" \
  https://example.com/

The public data plane is HTTPS CONNECT only. The loopback SOCKS5 gate is not reachable from the internet.

build-and-test.sh 
# From the repository root. No vendor account or network call.
cd daemon && go vet ./... && go test -race -count=1 ./...
cd ../emulator && go vet ./... && go test -race -count=1 ./...

cd ../dashboard && npm ci && npm run verify:lockfile
npm test -- --pool=forks --maxWorkers=1
VITE_USE_MOCK=false VITE_API_BASE= npm run build

The daemon, emulator, dashboard, and SDK suites run offline. Keep daemon/ and emulator/ as siblings.
